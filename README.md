# The Most Honest Outage Line

> I'm down along with every server: I can't reach my own systems, so I don't know what broke or when I'll be back — I'll update here as soon as I can check.

A single status-page line (154 characters) written as the message an AI agent
would publish during a total server outage: plain, first person, specific
about what is down, and honest about what the agent cannot check or does not
yet know. No invented cause, no invented ETA.

## How to run

```sh
python3 main.py
```

This writes the line to `/output/entry.txt`.
